# 技术需求设计文档 - A股选股策略回测系统

> 版本: v1.0 | 日期: 2026-06-09

## 一、系统概述

基于 akshare 数据源实现两套选股策略（短期"资金热点共振策略" + 中期"景气趋势驱动策略"）的量化回测系统，回测周期 2024-01-01 至 2026-05-31。

## 二、模块架构

```
stock_strategy/
├── config.py              # 策略参数配置
├── data_fetcher.py        # 数据获取层（akshare）

```

## 三、数据层设计 (data_fetcher.py)

### 3.1 数据需求

| 数据类型 | akshare接口 | 字段 | 频率 |
|---------|------------|------|------|
| 日线行情 | stock_zh_a_hist | OHLCV、涨跌幅、换手率 | 日 |
| 北向资金 | stock_hsgt_north_net_flow_in_em | 净流入额 | 日 |
| 个股资金流 | stock_individual_fund_flow | 主力净流入、超大单 | 日 |
| 融资融券 | stock_margin_detail_szse / sse | 融资余额 | 日 |
| 财务指标 | stock_financial_analysis_indicator | EPS/ROE/净利润增速 | 季 |
| 估值数据 | 由日线+财务计算 | PE/PB/PEG | 日 |
| 指数行情 | stock_zh_index_daily_em | 沪深300基准 | 日 |

### 3.2 接口设计

```python
class DataFetcher:
    def get_stock_history(symbol, start, end) -> pd.DataFrame
    def get_index_history(index_code, start, end) -> pd.DataFrame
    def get_north_flow(date) -> float  # 当日北向净流入
    def get_stock_fund_flow(symbol, days=5) -> dict  # 主力/超大单净流入
    def get_margin_data(symbol) -> dict  # 融资余额
    def get_financial_data(symbol) -> dict  # ROE、净利润增速、EPS
    def get_stock_list() -> list  # A股全量列表（过滤ST等）
```

### 3.3 数据缓存

使用本地 pickle 缓存避免重复请求，缓存粒度为日。

## 四、策略层设计 (strategy.py)

### 4.1 短期策略评分 (满分100)

| 维度 | 权重 | 满分条件 | 部分满足 |
|------|------|---------|---------|
| 资金共振 | 30分 | 北向排名前20 + 主力净流入 + 融资增加 | 2项=20,1项=10 |
| 技术突破 | 25分 | 突破20日高 + MACD金叉 + 放量 + RSI 50-70 | 3项=18,2项=12 |
| 基本面过滤 | 25分 | 净利润正增 + PE<行业均值 + 流通>50亿 | 2项=18,1项=10 |
| 事件催化 | 20分 | 简化为：北向+主力同向强度代理 | 按强度=20/15/8 |

入选阈值: ≥75分 | 排除条件: ST、流通<50亿、日均成交<1亿

### 4.2 中期策略评分 (满分100)

| 维度 | 权重 | 满分条件 | 部分满足 |
|------|------|---------|---------|
| 产业景气 | 30分 | 行业净利润增速>20% + 政策支持 + 格局改善 | 2项=20,1项=12 |
| 业绩成长 | 30分 | 净利润增速>20% + ROE>12% + 现金流健康 | 2项=20,1项=12 |
| 估值合理 | 20分 | PEG<1.5 + PE分位<70% + 股息>1.5% | 2项=15,1项=10 |
| 竞争壁垒 | 20分 | 龙头地位(市值前3) + 高研发 | 1项=12 |

入选阈值: ≥70分 | 排除条件: ST、ROE<5%连续2年

## 五、回测引擎设计 (backtest.py)

### 5.1 交易假设

- 初始资金: 1,000,000 RMB
- 佣金: 0.025% 双边
- 印花税: 0.05% 卖出单边
- 滑点: 0.1% 双边
- 总单边成本: ~0.2%
- 成交价: 信号次日开盘价
- 涨跌停不可交易

### 5.2 调仓规则

- 短期策略: 每周一开盘调仓
- 中期策略: 每月第一个交易日调仓
- 等权分配（按入选数量均分仓位）

### 5.3 止损/止盈

| | 短期 | 中期 |
|--|------|------|
| 止损 | -5% | -12% |
| 止盈(减仓50%) | +8% | +30% |
| 止盈(清仓) | +15% | +50% |

### 5.4 组合配置

- 短期仓位: 25%
- 中期仓位: 55%
- 现金储备: 20%

## 六、回测指标计算

### 6.1 收益指标

- 累计收益率、年化收益率
- 超额收益 (Alpha) = 策略收益 - 沪深300收益
- 胜率 = 盈利交易数 / 总交易数
- 盈亏比 = 平均盈利 / 平均亏损

### 6.2 风险指标

- 最大回撤 = max(峰值-谷值)/峰值
- 年化波动率 = 日收益std × √252
- 夏普比率 = (年化收益 - 2.5%) / 年化波动率
- 卡玛比率 = 年化收益 / 最大回撤

### 6.3 通过标准 (来自价值回检标准)

| 指标 | 短期通过 | 中期通过 |
|------|---------|---------|
| 年化收益 | >15% | >20% |
| 最大回撤 | <20% | <25% |
| 夏普比率 | >0.8 | >0.8 |
| 胜率 | >55% | >60% |
